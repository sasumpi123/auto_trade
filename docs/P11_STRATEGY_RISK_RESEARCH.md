# P11-A — 실제 과거 데이터의 전략·위험관리 비교

이 결과는 **이미 공개한 train/validation을 재사용한 탐색적 연구**다. 수익률 최적화, 운영 전략 변경, 독립 검증 또는 실거래 성과가 아니다. 기존 스냅샷과 고정 비용으로 3,072개 단일 종목 시뮬레이션을 수행했다. 실제 Upbit API/주문, Slack 발송, MacBook 접속·배포, 모델 자동 실행은 하지 않았다. 기존 추가 지출 0원 및 모든 비활성 정책을 유지한다.

결과 전체: [연구 요약](../research/p11-risk-2026-10-23/README.md), [전체 지표 CSV](../research/p11-risk-2026-10-23/metrics.csv), [대응 차이 CSV](../research/p11-risk-2026-10-23/paired_deltas.csv), [프로토콜·해시·지표 JSON](../research/p11-risk-2026-10-23/results.json). 표의 평균은 별도 초기 자금 계정들의 기술통계이며 **포트폴리오 수익률이 아니다**.

## 계약과 데이터 사용 경계

기존 `backtesting/protocol.json`, `research/2026-10-21/data/` 및 원래 결과를 변경하지 않았다. 새로운 `backtesting/risk_protocol.json`은 오버레이 성과 계산 전에 커밋 `108a311`로 고정했다. SHA-256은 `d5086b966a1b5327f485983f548a45369ee631a25f1f80bd65c420e2f9316c2c`이다. 코드가 고정 프로토콜과 다르면 실행을 차단한다. 날짜/종목/비용/임계값을 결과에 맞춰 바꾸거나 최고 조합을 선택하지 않는다.

| 구간 | UTC 봉 시작, 시작 포함·끝 제외 | 이번 사용 |
|---|---|---|
| train | 2026-07-23 ~ 2026-09-15 | 공개된 54일 재사용 |
| validation | 2026-09-15 ~ 2026-10-03 | 공개된 18일 재사용; 독립 검증 아님 |
| holdout | 2026-10-03 ~ 2026-10-21 | 행 파싱·지표·손익 계산 없음 |

4종목 BTC/ETH/XRP/SOL × 15/60분의 개발 접두 구간만 사용한다. 각 15분 데이터는 train 5,184 + validation 1,728행, 60분은 1,296 + 432행이다. 개발 구간의 누락·중복·역순·비유한 값·OHLC 경계·시간 그리드를 기존 검사로 확인했으며 8개 모두 통과했다. 각 train/validation 정규화 SHA-256이 원래 manifest와 일치해야 평가한다. 누락 봉을 채우거나 표본을 성과에 따라 제거하지 않는다.

**기존 gzip에는 holdout도 함께 있다.** 새 `load_development`는 달력으로 결정한 헤더+개발 행 수만 readline으로 요청하고 다음 행을 미리 읽지 않는다. 행 수·경계·해시가 다르면 중단한다. 기존 실제 스냅샷 회귀 테스트 두 개도 전체 파일/holdout 읽기 대신 이 경로를 사용한다. 테스트 수/기존 개발 지표 재현은 유지한다. 합성 poison-tail 및 readline 횟수 테스트로 행 파싱 경계를 검증한다.

gzip/텍스트 버퍼는 압축 tail 바이트를 내부 선읽기할 수 있다. 따라서 **holdout 행을 파싱·분석하지 않았다는 보장이지 바이트 단위 접근 격리 보장이 아니다**. 이번에는 전체 압축 파일 해시/EOF CRC/holdout 품질을 재검사하지 않았다. 원래 manifest의 전체 해시는 기록으로만 보존한다. 기존 연구 때 기록된 holdout 누락 진단도 새 데이터로 열지 않았다. 물리적 완전 격리가 필요하면 사용자가 별도 승인한 데이터 보관 설계가 필요하며, 이번 단계에서 holdout을 열어 분리하지 않는다.

## 동일 조건의 가설 비교

RSI, MACD, 볼린저, 반대 표 없는 2/3 합의, 3/3 합의, 기존 순차 우선순위를 보존한 `legacy_composite`를 그대로 사용한다. 각각 다음 5가지 고정 오버레이를 비교한다. 추가 40%/100% buy-and-hold 기준선은 신호 전용으로만 계산한다.

| 오버레이 | 보유 중 완료 종가에서의 동작 |
|---|---|
| signal_only | 기존 신호만 적용 |
| take_profit_5 | 평균 체결가격 대비 +5% 이상이면 전량 매도 예약 |
| stop_5 | -5% 이하면 물타기 없이 전량 매도 예약 |
| take_profit_stop_5 | 위 익절과 단순 손절 결합 |
| take_profit_average_once_5 | +5% 익절, -5%에서 1회 물타기, 변경 평균가격 대비 다시 -5%면 전량 매도 예약 |

마지막 행이 기존 운영 봇의 가격 보호 **정책 가설**에 대응한다. `stop_5`는 원래 운영 손절이라고 주장하지 않는 비교용 ablation이다. 운영 봇은 tick 가격으로 처리하지만 연구는 완료 봉 종가에서만 관찰하고 다음 봉 시가에 실행한다. 같은 실시간 체결을 재현한 것이 아니다.

- 익절 우선, 그 다음 손절/물타기, 그 다음 일반 신호 순서다. 가격 보호는 신호용 거래량·쿨다운 필터보다 먼저 적용한다. 보호 동작이 예약되면 같은 봉의 일반 신호는 사용하지 않는다.
- 보호 임계값의 평균가격은 운영 엔진과 같은 **매수 수수료 제외 가중 평균 체결가격**이다. 손익 계산용 수수료 포함 취득원가와 혼동하지 않는다. 물타기 후 새로운 평균가격으로 임계값을 다시 계산한다.
- 물타기 예산은 관찰 당시 보유수량 × 완료 종가 × 0.5, 현금 한도로 제한한다. 다음 시가에서 수수료 포함 all-in 예산 안의 소수 8자리 수량을 내림한다. 최소 주문/수량 제약으로 실행할 수 없으면 같은 실행 시가의 매도로 전환한다. 성공 체결 없이 물타기 완료로 기록하지 않는다. 해당 비용/시차 모델은 현재 PAPER 수수료 0원/즉시 체결과 다르다.
- 매 포지션의 1회 한도는 전량 매도 후에만 초기화된다. 미확정 실주문 복구 한도와 무관한 메모리 연구 상태이며 운영 원장/한도를 수정하지 않는다.
- 종목·구간·전략·비용별 초기 현금 100만원, 초기 매수 예산 40만원을 유지한다. **매 봉 40%로 리밸런싱하는 것이 아니다.** 물타기나 가격 변동으로 실제 노출이 40%를 넘을 수 있다. 100% 보유 기준선은 별도 표시한다.
- train/validation의 현금·포지션은 각각 초기화한다. validation 지표 문맥만 앞선 train 봉을 사용한다. 공통 지표 워밍업(첫 유효 신호 인덱스 34), 원래 RSI/MACD/BB 정의, 거래량 필터 0.5배, 신호 쿨다운 300초, 최소 주문 5,000원, 무차입, long-only, 동시 한 종목을 유지한다. 검증 첫 봉 이전 신호/포지션을 넘기지 않는다.

2구간 × 8데이터 × 6비용 × (6전략 × 5오버레이 + 2보유기준선) = **3,072개**다. 신호 전용 768개는 원래 공개 결과의 모든 기존 지표와 절대 오차 1e-8 이내 일치했다. 나머지 2,304개에는 같은 종목·구간·전략·비용의 신호 전용 대비 차이를 기록했다. 소스/세그먼트 해시와 체결 trace 해시를 보존한다.

## 손익·위험·비용 지표

- 매수 취득원가 = 체결 거래금액 + 매수 수수료. 추가 매수는 취득원가/수량을 합한다. 전량 매도 실현손익 = 매도 거래금액 − 매도 수수료 − 전체 취득원가. 미실현손익 = 마지막 종가 × 잔여 수량 − 잔여 취득원가. 순손익 = 현금 + 보유 종가평가액 − 초기 현금. 원가/현금 대사와 이 식을 회귀 테스트한다.
- 순수익률 = 순손익 / 초기 현금. 승률 = 순실현손익 양수인 **종료 포지션 수** / 종료 포지션 수. 0원은 승리 아님, 종료 거래 0이면 N/A다. fill_count는 매수·물타기·매도 수이고 closed_trades는 전량 매도 수다. 둘을 섞지 않는다.
- MDD는 초기 현금부터 **종가 평가** 고점 대비 낙폭이다. 장중 최저 가격/체결 직후 변동·청산 손실을 완전히 포착하지 않는다. 마지막 보유를 가상 청산하지 않아 미발생 청산 수수료/슬리피지는 제외된다.
- 시장 노출은 매 봉 종가 기준 보유 평가액 / 총 평가자산의 시간 평균·최댓값, invested_bar_pct는 보유한 봉의 비율이다. 준비/비보유 봉도 해당 구간 분모에 포함한다. 시간 평균과 고정 매수 예산은 다른 값이다.
- 수수료 5/10bps × 슬리피지 0/5/10bps **6조합 전부**, 전체 spread 2bps의 반을 매수/매도 각각 반영한다. 기본 표시값은 5/5/2다. 매수 가격 = 시가 × (1 + (slippage + spread/2)/10,000), 매도는 반대다. 수수료는 이 체결가격 기준 거래금액에 적용한다. `total_fees`는 명시적 수수료만이며 slippage/spread는 이미 체결가격·손익에 반영된다.
- spread는 기존 계약대로 2bps 고정이며 새 spread 그리드를 최적화하지 않았다. 비용에 따라 체결 평균가격/이후 위험 트리거도 달라질 수 있어 모든 경로가 단조적으로 변한다고 가정하지 않는다.

### P9-A/PAPER 원장과의 관계

P9-A의 수수료 포함 순실현/평가손익과 경제적 정의는 같다. 기존 운영 원장의 `profit_amount`는 수수료 제외 평균가격 기준 값이므로 연구 순손익으로 덮어쓰거나 동일하다고 하지 않는다. P9-A는 영속 원장의 확정 체결/부분 매도/취소/시간·수치 증거를 검증하는 읽기 전용 계층이다. 이 연구는 영속 주문 원장이 없고 **전량 가정 체결**만 있으며 부분 체결·부분 매도·미확정 주문/재시작 복구를 구현하지 않는다. PAPER의 현재 fee=0과 연구 비용도 다르다. 연구 결과를 운영 Slack 성과나 실제 확정 주문으로 보내지 않는다. 일간 평가자산 snapshot/일간 총수익률도 만들지 않는다.

## 관측 결과와 해석

다음은 기본 비용의 validation에서 기존 복합 전략의 신호 전용 → 익절+1회 물타기 비교다. 평균은 8개 별도 계정의 단순 기술통계이며 독립 표본·포트폴리오 손익이 아니다.

| 항목 | 신호 전용 | 익절+1회 물타기 |
|---|---:|---:|
| 종목·주기별 순수익률 평균 | -0.802% | -0.796% |
| 최악 계정 MDD | 6.754% | 7.046% |
| 수수료 평균 | 5,372.046원 | 5,493.109원 |
| 체결 수 합계 / 종료 포지션 합계 | 215 / 105 | 220 / 106 |
| 계정별 승률 평균 (8/8 종료 거래 있음) | 63.719% | 63.987% |
| 시장 노출 평균 | 15.051% | 15.162% |

평균 수익률의 약 0.007%p 차이를 개선 효과라고 단정할 수 없다. XRP 15분은 순수익률 -6.019→-6.312%, MDD 6.754→7.046%, 수수료 8,174.179→8,951.552원으로 악화했다(물타기 2회, 서로 다른 포지션). SOL 15분은 -3.334→-2.987%, MDD 4.305→3.958%로 개선했지만 수수료·노출이 늘었다(물타기 1회). 나머지 여섯 계정은 이 오버레이에서 동일했다. 평균만 보면 이 상반된 위험이 가려진다. train에서도 평균 수익률은 -1.188→-0.944%였지만 최악 MDD는 6.285→6.519%로 커졌다.

3/3 합의는 모든 비용·구간에서 **0체결**, 노출 0%, 승률 N/A다. 0% 수익률/낙폭을 우수한 방어 성능으로 해석하지 않는다. 기본 비용의 validation 2/3 합의 신호 전용은 평균 1.804%지만 8개 데이터 전체 종료 포지션이 12개뿐이고 두 계정은 종료 거래가 없다. 최고 후보를 선정하거나 통계적 유의성을 주장할 표본이 아니다. 볼린저의 이 구간 보호 오버레이 결과가 동일한 것도 효과 입증이 아니라 해당 보호 트리거가 추가 경로를 만들지 않은 표본이라는 뜻이다.

비용은 무시할 수 없다. 기존 복합 전략 validation의 신호 전용 평균 순수익률은 수수료/슬리피지 5/0bps에서 -0.265%, 5/5bps에서 -0.802%, 10/10bps에서 -1.875%다(spread 모두 2bps). 상대적으로 잦은 거래와 비용이 성과를 좌우한다. 보유 기준선 40%의 validation 평균은 +3.704%, 100%는 +9.261%지만 시장 노출도 다르다. 이것을 위험 조정 우위나 향후 보유 추천으로 해석하지 않는다.

## 누수·체결 가정·편향의 한계

완료 봉에서만 순방향 rolling/EWM 지표를 계산하고, bfill/ffill 없이 공통 워밍업을 적용한다. 완료 시각 이전 봉만 신호가 보고 다음 봉 시가에 실행한다. 미래 구간을 바꿔도 이전 지표/체결이 변하지 않는 테스트, intrabar 고저가를 보지 않는 테스트, 최종 신호 미체결 테스트를 추가했다. 이 검사는 구현된 규칙의 인과성을 검증할 뿐 모든 연구 편향을 제거하지 않는다.

- OHLCV만으로 같은 봉 안의 가격 경로, stop/take 동시 충족 순서, 호가 깊이, 주문 지연/시장 충격/최소 주문의 실제 거래소 제한, 부분 체결·취소를 알 수 없다. 다음 시가 전량 체결은 연구 가정이다. -5% 관찰 후 갭 하락하면 5% 이상 손실이 가능하고, 지연 체결로 다른 결과도 가능하다.
- train 54일/validation 18일의 짧은 고정 구간이며 validation은 이미 공개됐다. 후속 가설 설정에 이전 결과를 알 수 있으므로 독립 검증이라고 부를 수 없다. 다중 전략·시장·비용 비교 자체에 선택 편향이 있다. 유의성 검정/연율화 Sharpe/신뢰구간을 표본 근거 없이 만들지 않았다.
- 네 자산과 두 주기는 상관되어 있고 같은 시장 움직임을 중복 관측한다. 현재 알려진 유동성 자산의 고정 선택은 과거 시점 전체 투자 가능 universe/상장폐지 자산을 포함하지 않아 생존·선정 편향이 남는다. 이번 표본의 보유 기준선 상승도 시장 국면 의존성을 보여준다.
- `legacy_composite`는 기존 신호 규칙 비교이며 tick 기반 운영 봇 전체 성과가 아니다. 다종목 공유 자금, 동시 보유 상한/종목 경합, 거래소 복구는 연구에 없다. **다종목 포트폴리오 결과는 미구현/N/A**이고 계정 평균으로 대체하지 않는다.

## 재현 및 다음 실험

추가 API/데이터 수집이나 새 의존성 설치가 필요 없다. Python 3.12와 기존 requirement.txt 환경에서 실행한다. 새 출력 경로가 이미 있으면 실패하며 원본/이전 보고서를 덮어쓰지 않는다.

```sh
python -m backtesting.risk_research --data research/2026-10-21/data --baseline-results research/2026-10-21/results.json --output runtime/p11-reproduction
python -m backtesting.risk_report runtime/p11-reproduction
python -m unittest tests.test_p11_risk_research -v
python -m unittest discover -v
python tools/check_safety.py
```

첫 명령이 JSON/전체 CSV/대응 차이 CSV/Markdown을 생성한다. 두 번째 명령은 계산 없이 같은 JSON의 기술통계 표를 재생성한다. 런타임 버전 메타데이터는 환경마다 다를 수 있으며 비교할 대상은 입력/프로토콜/체결 trace 해시와 수치다. CI는 전체 기존 테스트와 신규 회귀, 실제 XRP 15분 validation의 신호 전용/물타기 체결 trace·지표 재현, 고정 그리드/원가 대사를 검증한다. 전체 3,072개 sweep는 Cloud에서 수행했으며 CI가 매 OS마다 전체 sweep를 반복했다고 주장하지 않는다.

다음 실험은 결과 기반 파라미터 튜닝 대신 별도 사전 고정 계약·새 독립 데이터 사용 승인부터 진행한다. 기존 미사용 holdout은 계속 보존한다. 장기/다른 시장 국면 및 point-in-time universe, 독립 증거 있는 체결/호가 가정, 별도 승인된 부분 체결 모델, 실제 구현된 공유 자금 포트폴리오 비교를 순서대로 검토할 수 있다. 어떤 연구 후보도 운영 기본값이나 실제 거래/Slack/자동화로 자동 반영하지 않는다.

후속 [기존 운영 전략 진단과 PAPER 체결 연결](P11A_STRATEGY_DIAGNOSTICS.md)은 실제 DataAnalyzer/AutoTrade/ExecutionEngine/P9 회계 경로를 별도 오프라인 연구에 연결한다. 기존 위험관리 비교 결과를 대체하거나 운영 전략을 변경하지 않으며, 15/60분 개발 자료와 미확보1분봉/봉별 단일 평가 가정을 구분한다.
