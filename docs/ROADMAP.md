# 개발 로드맵

대화 이력 없이도 다음 작업을 판단할 수 있도록 단계별 완료 조건, 차단 조건, 선행 작업을 정리합니다.
이 문서는 작업을 자동으로 예약하거나 실행하는 설정이 아닙니다. 진행률을 숫자로 표시하지 않으며, 미래 수익을 약속하지 않습니다. 실제 계좌·잔고·체결·기기 경로·운영 로그는 이 문서에 옮기지 않습니다.

## 1. 이미 구현된 범위

**PAPER 거래·회계·운영 보호**
- 구현 내용: P9 회계, P17 체결, PAPER 실험 계좌, 수동 재개(P26), 입력 격리(P25), 스트림 진단(P23/P24)
- 확인된 근거: 합성 또는 가짜 응답을 쓴 테스트와 macOS CI
- 미확인: 장시간 실자료 PAPER의 안정성

**측정 도구**
- P28: 가상 청산 비용
- P29: 현금 100%와 매수보유 40% 기준선
- P30: P22 사후 보조 감사
- 확인된 근거: 합성 fixture와 CI
- 미확인: 사용자 실자료에 대한 실행 결과

**P22 고정 전방 평가**
- 기간: UTC [2026-11-03, 2026-11-06), 종목: BTC/XRP, 비용: 5/5/2bps, 44bps 진입 필터
- 사전에 고정된 프로토콜·등록·소스 해시를 따릅니다.
- P25 이후로는 `tools/p22_isolated.py`로만 실행합니다.

## 2. 단일 수동 연구 명령 (P31, 이슈 #65) — 완료

- [PR #66](https://github.com/sasumpi123/auto_trade/pull/66)으로 병합됐습니다. macOS CI와 Safety gate가 통과했습니다.
- `python -m ops.research_run p22`는 수집 → 격리 평가 → 조건부 보조 감사를 각각 1회만 실행합니다.
- 재시도·예약·frozen 우회는 없습니다.

## 3. P22 실자료 수집·고정 평가·사후 보조 검사

- **선행:** 2번 병합. 2026-11-06 09:00 KST 이후 사용자가 명시적으로 수동 실행합니다.
- **완료 조건:**
  - 원래 사전 등록된 결과(`VERIFIED`/`VERIFIED_PARTIAL`/그 외)와 P30 보조값을 분리해 기록하고 검토합니다.
  - 원래 판정을 우선합니다. 보조값으로 소급해서 성공 처리하지 않습니다.
- **차단 조건:**
  - 수집 상한 초과
  - 해시나 입력의 불일치
  - 미완료 결과: 실패로 보고하며, 재수집하거나 기간을 바꾸지 않습니다.

## 4. 결과에 근거한 후보 판단

- **현재 판단:** P22 결과를 검토한 뒤 **44bps 진입 필터의 운영 채택은 보류**했습니다.
  - 이 판단이 후보의 미래 가능성을 통계적으로 영구 기각한다는 뜻은 아닙니다.
  - 원래 P22의 상태·파일·등록 해시는 변경하지 않았습니다.
- **판단 원칙:**
  - 결과에 따라 보류, 기각, 추가 검증 중 하나로 정합니다.
  - 나쁜 결과가 나와도 임계값이나 기간을 재탐색하지 않습니다.
  - NO_TRADES는 개선으로 보지 않습니다.
  - 현금이나 BH40 대비 손실은 그대로 보고합니다.
- **P32 (이슈 #67), 기존 `ConsensusStrategy(2)` 개발 비교:**
  - P17/P9 비용 조건에서 기존 P19 개발 자료로만 Legacy·44bps와 비교합니다.
  - 새 전략도, 독립 검증도 아닙니다.
  - 선행 조건: P32 병합 후 사용자가 기존 P19 입력을 명시해 수동으로 한 번 실행하고, ChatGPT가 결과를 검토합니다.
  - 다음 결정: 후보를 유지·보류·중단 중에서 정합니다. 세 후보 모두 근거가 부족하면 억지로 운영에 채택하지 않습니다.
  - 유리한 후보가 있어도 개발 표본 결과일 뿐입니다. 새 사전 고정 평가 없이 수익성 입증이나 실거래 전환으로 이어지지 않습니다.

- **P33 (이슈 #69), Consensus 2/3 전방 평가 사전등록 제안:**
  - 후보는 계속 **운영 보류** 상태입니다.
  - 지금은 사전등록 **리뷰 단계**입니다: `backtesting/p33_protocol.json` 제안, UTC [2026-11-08, 2026-11-15).
  - 시작 전 승인과 등록 영수증이 모두 있어야 전방 평가로 인정합니다. 기한을 놓치면 이번 창은 차단됩니다.

## 5. 다음 표본과 장시간 PAPER

- **선행:** 다음 표본이 필요하면 별도의 사전 고정 계획(날짜·종목·비용·지표)을 먼저 검토하고 승인받습니다.
- **그 뒤에 할 일:**

## 6. 실거래 전환 없음

- 다음 두 가지가 모두 갖춰지기 전에는 실거래로 전환하지 않습니다.
  - 충분한 수익·위험 증거
  - 사용자의 별도 명시 승인
- `REAL_TRADING=False`를 유지합니다.
- 추가 지출은 0원입니다. 유료 API·모델·인프라는 쓰지 않습니다.
- Slack, launchd, 무인 실행, 자동 병합은 계속 꺼 둡니다.
