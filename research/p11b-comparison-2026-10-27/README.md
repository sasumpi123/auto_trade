**완료: 6전략 ×4종목 ×2주기 ×2개발구간 ×6비용 =576개 비교.** Legacy96개 기존 결과와 counts/fills/metrics/비용/최종자산/data hash/전체trace hash가 모두 일치했다. 미래 holdout 행 파싱·평가0, 독립 검증 아님, 운영 전략 선정/변경 없음.

실제 계산 환경: Cloud Linux Python3.12.14, pandas3.0.6, numpy2.5.4. 실제576개 계산은 이 환경에서 수행했고3OS CI는 코드/synthetic 회귀를 검증한다. [계산·자료·통계 계약](../../docs/P11B_STRATEGY_COMPARISON.md).

자료: BTC/ETH/XRP/SOL의15/60분. train [2026-07-23,2026-09-15), validation [2026-09-15,2026-10-03) UTC. 이미 공개된 개발 자료다. 운영1분봉은 **INSUFFICIENT_REAL_DATA**다.
